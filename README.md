# Valyou Web — Fairness in Every Square Meter

Valyou is an automated real estate valuation platform designed to eliminate subjectivity and provide transparent, data-driven property appraisals.

## Features
- **Geospatial Pin-Drop**: Interactive OpenStreetMap coordinate picker with automated reverse geocoding.
- **3-Step Appraisal Wizard**: Seamless flow for property specifications, dimensions, and condition assessment.
- **Project NOAH Integration**: Interactive climate and disaster risk overlays for 5-year flood return intervals, landslide susceptibility, storm surge zones, and a composite all-hazards layer.
- **Automated Valuation Breakdown**: Transparent appraisal calculations factoring in baseline asking anchors, structural condition deductions, and environmental risk adjustments.
- **Responsive Memphis Design**: Vibrant, accessible interface built with React 19, TypeScript, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
